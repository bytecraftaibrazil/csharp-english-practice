# C# English Practice

**Practicing technical English through C#, .NET, and ASP.NET Core.**

This repository is primarily about **improving my English in a software development context**. I already have experience with C# and the .NET ecosystem, so I'm using courses taught in English as an opportunity to strengthen my listening comprehension, expand my technical vocabulary, and become more comfortable explaining programming concepts in English.

The code here supports that language practice. It is not intended to represent my first steps in programming.

## Main Goals

- Improve my understanding of spoken English in technical lessons.
- Expand my English vocabulary for software development.
- Practice reading and writing technical explanations in English.
- Get more comfortable discussing familiar programming concepts in English.
- Organize exercises and notes from different English-language courses.

## Repository Structure

Each course will have its own folder, organized by topic:

```text
csharp-english-practice/
├── csharp/
│   └── course-name/
└── README.md
```

Folders will be added as I complete courses. They may include code exercises, examples, and notes written in English.

## Why C# and .NET?

I'm using technologies I'm already familiar with so I can focus more on **the language of software development**: how concepts are explained, which terms are commonly used, and how to communicate technical ideas naturally in English.

**The main challenge here is English, not starting programming from scratch.**
